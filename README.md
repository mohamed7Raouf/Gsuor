# جسور (Josour) — تطبيق ويب ثابت (Static Web App)

منصة ويب عربية تفاعلية لعرض البيانات الحية مع استوديو تصدير يومي لصور الستوري وفيديوهات الريلز المتحركة (9:16 - 10 ثوانٍ)، بالإضافة إلى صفحة البث المباشر للحرم المكي متعددة الجودات.

يعمل المشروع بالكامل كواجهة أمامية مستقلة (**Static Web App**) بدون قاعدة بيانات أو خادم خلفي، مع تخزين التفضيلات واللقطات في المتصفح (`localStorage`) وتحديث البيانات من الواجهات العامة مباشرة مع بيانات افتراضية مدمجة.

## النشر التلقائي على GitHub Pages

المشروع مضبوط للعمل على المسار:
`https://wowstoresms-rgb.github.io/gesour/`

1. تأكد أن مستودع GitHub اسمه `gesour` وفرعه الرئيسي `main`.
2. من إعدادات المستودع على GitHub: **Settings -> Pages -> Source** اختر **GitHub Actions**.
3. عند كل `push` على فرع `main` يعمل ملف `.github/workflows/deploy.yml` تلقائياً لبناء مجلد `dist` ونشره على GitHub Pages.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ولبناء نسخة الإنتاج الثابتة داخل مجلد `dist`:

```bash
npm run build
```
